# Licença das fontes

Esta pasta contém quatro arquivos WOFF2 copiados do build local do Google Fonts (subconjunto `latin`), sem modificação além do recorte feito pelo Google:

| Arquivo | Família | Peso |
|---|---|---|
| `literata-latin.woff2` | Literata | variável (200 a 900) |
| `fira-500-latin.woff2` | Fira Sans | 500 |
| `fira-600-latin.woff2` | Fira Sans | 600 |
| `plex-mono-latin.woff2` | IBM Plex Mono | 400 |

Todas as fontes estão sob a **SIL Open Font License, versão 1.1 (OFL 1.1)**.

O texto completo da licença, junto com o aviso de copyright de cada família, está nos arquivos correspondentes:

- `OFL-Literata.txt`: Literata
- `OFL-FiraSans.txt`: Fira Sans
- `OFL-IBMPlexMono.txt`: IBM Plex Mono

Ao redistribuir estes arquivos, mantenha os `OFL-*.txt` junto deles.
